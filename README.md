## What I'm building

### 🤖 [CAD AI](https://github.com/Evo1148/CAD-AI)

A local-first system that turns natural-language requirements into validated parametric CAD.

```text
Natural language
      ↓
Deterministic grounding
      ↓
Structured facts / LLM extraction
      ↓
DesignSpec
      ↓
CADPlan
      ↓
CAD engine
      ↓
Validator
      ↓
Repair loop
      ↓
STEP / STL
```

**Tech:** Python · CadQuery · OpenCascade · local LLMs · structured output · automated testing

### 🎛️ [DIY Stream Deck](https://github.com/Evo1148/streamdeck-diy)

A custom Stream Deck built from scratch around an RP2040, including the electronics, firmware, enclosure and Windows configuration software.

- 12 mechanical keys
- Rotary encoder with push button
- 480×320 display
- USB HID keyboard and media controls
- Custom vendor HID protocol
- Persistent on-device bindings
- Windows configuration app
- Custom 3D-printed enclosure

**Tech:** C/C++ · Pico SDK · TinyUSB · RP2040 · C# · WinUI · HID · 3D printing
