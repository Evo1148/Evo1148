## En qué estoy trabajando

### 🤖 [CAD AI](https://github.com/Evo1148/CAD-AI)

Un sistema local-first que transforma requisitos en lenguaje natural en CAD paramétrico validado.

```text
Lenguaje natural
      ↓
Grounding determinista
      ↓
Hechos estructurados / extracción con LLM
      ↓
DesignSpec
      ↓
CADPlan
      ↓
Motor CAD
      ↓
Validator
      ↓
Repair loop
      ↓
STEP / STL
```

**Tecnologías:** Python · CadQuery · OpenCascade · LLMs locales · structured output · testing automatizado

### 🎛️ [DIY Stream Deck](https://github.com/Evo1148/streamdeck-diy)

Un Stream Deck personalizado construido desde cero alrededor de un RP2040, incluyendo electrónica, firmware, carcasa y software de configuración para Windows.

- 12 teclas mecánicas
- Encoder rotatorio con pulsación
- Pantalla 480×320
- Teclado USB HID y controles multimedia
- Protocolo Vendor HID propio
- Configuración persistente en el dispositivo
- Aplicación de configuración para Windows
- Carcasa personalizada impresa en 3D

**Tecnologías:** C/C++ · Pico SDK · TinyUSB · RP2040 · C# · WinUI · HID · impresión 3D
